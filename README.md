# نور الإيمان

موقع ثابت (HTML/CSS/JS) بلا مكتبات خارجية، يعمل على GitHub Pages مباشرة.

## المحتوى
| القسم | المحتوى | المصدر |
|---|---|---|
| الأدعية | العشرات، الافتتاح، كميل، المشلول، الندبة، الصباح + الصحيفة السجادية (٥٤ دعاء) | ThaqalaynData عبر `shia-library-json` (CC0) |
| الزيارات | عاشوراء، الأربعين، وارث، الجامعة الكبيرة، آل ياسين | نفس المصدر |
| نهج البلاغة | ٢٤١ خطبة، ٧٩ كتاباً، ٤٧٠ حكمة (مشكّلة) | مستودع `WWGTX/NahjulBalaghah` |
| غرر الحكم | ١١٬١٩٣ حكمة مرتبة بالموضوعات (٢٥ باباً) | OpenITI — طبعة مصطفى درايتي (مكتبة مساحة) |
| توقع الأهلة | حساب فلكي لكل الأشهر حتى ~١٥٥٠ هـ | `hilal.js` |
| القمر في العقرب | وقت دخول القمر برج العقرب وخروجه في كل شهر هجري (٢١٠°–٢٤٠° مدارية، بتوقيت بغداد) | `hilal.js` (`scorpioPeriods`) |
| آداب الحلاقة وقص الأظافر | يوم الأسبوع/الشهر وفائدته مع المصدر | `adab/*.json` |

## الملفات
`index.html` الصفحة · `style.css` · `app.js` التاريخ الهجري والمناسبة · `library.js` الأقسام والتنقل · `hilal.js` محرك الأهلة · `occasions.js` المناسبات · `qrcode.js` (MIT) · `duas/` و`nahj/` و`ghurar/` النصوص (تُحمَّل عند الطلب).

## توقع الأهلة
- يحسب الموقعَ الفلكي للشمس والقمر (Meeus، دقة الاقتران ±دقيقة تقريباً) ويقيّم الهلال مساء التاسع والعشرين من كل شهر في النجف الأشرف بمعيار Odeh.
- إن كانت `V ≥ 2` (قابلة للتعديل: `Hilal.cfg.MIN_V`) فالشهر الحالي ٢٩ يوماً، وإلا ٣٠.
- **هو تقدير فقط**؛ الثابت شرعاً ما ثبت بالرؤية وإعلان المرجعية. عند ثبوت هلال أضف سطراً إلى `MONTH_STARTS` في أول `app.js` فيُعتمد مرجعاً ويُعاد التوقع لما بعده تلقائياً:
```js
['2026-12-11', 1448, 7],   // [تاريخ الغرة الميلادي، السنة الهجرية، رقم الشهر]
```
- تحقّقتُ من المحرك بمقارنته بمكتبة `ephem`: الاقتران ±١ دقيقة، وارتفاع القمر وغروب الشمس متطابقان. لم أقارنه بإعلانات رؤية فعلية تاريخية.

## النشر
1. أنشئ مستودعاً جديداً وارفع كل الملفات إلى الجذر (مع مجلدات `duas` و`nahj` و`ghurar`).
2. Settings ← Pages ← Deploy from a branch ← `main` / `(root)`.
3. رابط المعاينة في `index.html` مضبوط على `https://lo-oxll.github.io/Noor_aliman/`.

## حدود معروفة وملاحظات الترخيص
- ليس «كل» الأدعية والزيارات: المتوفر ما في المصدر أعلاه فقط (مثل زيارة الإمام الحسين والعباس والرضا، ودعاء التوسل والفرج والعهد وأبي حمزة وغيرها غير مضمّنة بعد).
- نهج البلاغة: ٤٧٠ حكمة في المصدر المستخدم بينما ترقيم الطبعات الشائعة ٤٨٠؛ لم أتحقق من سبب الفرق.
- ترقيم غرر الحكم من المصدر، وفيه أخطاء ترقيم قليلة (١١ رقماً مفقوداً أو مكرراً).
- الأدعية/الزيارات CC0. أما نص نهج البلاغة (المستودع لا يحدد ترخيصاً) وغرر الحكم (OpenITI) فراجع شروط ترخيصهما قبل الاستخدام التجاري.

## القمر في العقرب وآداب الحلاقة والأظافر (داخل قسم الأهلة)
- المسارات: `#/hilal` (الأهلة) · `#/hilal/scorpio` · `#/hilal/adab` · `#/hilal/adab/nails` · `#/hilal/adab/haircut`.
- `Hilal.scorpioPeriods(fromMs, toMs)` تُرجع `[{enter, exit}]` بتوقيت UTC بالمللي ثانية، بنفس محرك الأهلة (خط الطول الظاهري للقمر). اختُبرت على الاقترانات المعروفة، لكنها لم تُقارَن بتقويم منشور.
- نصوص الحلاقة والأظافر في `adab/haircut.json` و`adab/nails.json`. لإضافة رواية: أضف كائناً إلى `weekdays` أو `monthDays` أو `general` بالحقول `{day|d, kind: "good"|"bad", text, src}`.
- **`haircut.json` فارغ عمداً**: لم أجد روايات موثّقة المصدر. ملخصات `nails.json` مأخوذة بالمعنى من منتديات الكفيل ولم تُراجع أسانيدها، فراجعها على الأصول (وسائل الشيعة، الفقيه، الخصال) قبل النشر.
